Arquitectura de Computadoras

Ingeniería en Sistemas Computacionales

Unidad 1: Arquitecturas de Cómputo

Teoría Fundamental

1.1 Modelos de Arquitecturas de Cómputo

Definición: Es el conjunto de reglas, principios y estándares que definen la estructura y el diseño de los componentes de hardware y software de un sistema informático.

Modelo Clásico (Von Neumann)

Creado en la década de 1940. Se basa en una Unidad Central de Procesamiento (CPU) que accede a una memoria compartida donde se guardan tanto los datos como los programas, comunicándose a través de un bus común. Esto genera un límite de velocidad conocido como el cuello de botella de Von Neumann.

Arquitectura Harvard

A diferencia de Von Neumann, utiliza memorias físicamente separadas para instrucciones (programas) y para datos. Esto permite a la CPU acceder a ambos flujos simultáneamente, mejorando drásticamente el rendimiento global.

Segmentado (Pipeline)

Divide el procesador en unidades funcionales independientes para realizar paralelamente varias etapas del ciclo de instrucción al mismo tiempo, emulando una línea de ensamblaje industrial.

Multiprocesamiento

Utiliza más de un procesador para ejecutar una aplicación y superar los límites de la segmentación. Se organiza según la Clasificación de Flynn en:

  • SISO: Monoprocesador clásico.
  • SIMO: Procesadores vectoriales.
  • MISO: Arquitectura teórica no implementada.
  • MIMO: Sistemas SMP, Clusters y GPUs modernas.

1.2 Análisis de los Componentes

Los elementos operativos del computador se categorizan en dos grandes ecosistemas:

Componentes Internos
  • Procesador (CPU): Cerebro lógico y aritmético del sistema.
  • Placa Base (Motherboard): Plataforma de integración que aloja el Firmware.
  • Fuente de Poder: Suministra y regula la energía eléctrica.
  • Memoria RAM: Almacenamiento volátil de acceso ultrarrápido.
  • Almacenamiento: Espacio permanente (SSD/HDD) para el SO.
  • Co-procesadores: Tarjeta de video (GPU), red, sonido y disipadores.
Componentes Externos (Periféricos)
  • Dispositivos de Entrada: Monitor táctil, teclado, mouse, escáner, micrófonos, webcams.
  • Dispositivos de Salida: Monitor principal, impresoras, altavoces, audífonos de monitorización.
  • Dispositivos Mixtos: Memorias de almacenamiento USB, unidades de red externas.

1.3 Enfoques de Arquitectura de Procesadores

RISC
Reduced Instruction Set Computer

Usa un conjunto de instrucciones reducido y optimizado. Ejecuta casi todas las instrucciones en un solo ciclo de reloj. Es la base de la eficiencia energética en teléfonos móviles (ARM) y servidores modernos.

CISC
Complex Instruction Set Computer

Utiliza un conjunto de instrucciones más amplio y complejo capaz de realizar tareas sofisticadas por ciclo. Facilita el desarrollo de software de alto nivel pero requiere microarquitecturas de decodificación masivas (x86).

1.4 Profundización en la CPU y Memorias

  • Componentes de la CPU: La ALU (Unidad Aritmética Lógica) ejecuta las operaciones matemáticas y lógicas elementales (AND, OR, sumas). La Unidad de Control (UC) interpreta, decodifica y coordina la ejecución de cada instrucción.
  • Tipos de Memoria Principal: La RAM es la memoria a corto plazo que actúa como búfer dinámico. La ROM es un almacenamiento no volátil permanente para el firmware de arranque básico (BIOS/UEFI). La Caché es memoria estática (SRAM) de velocidad extrema dividida en niveles (L1, L2, L3) para mitigar la latencia de la RAM.

1.5 Módulos de Entrada/Salida (E/S) y Gestión de Datos

  • Módulos de E/S: Interfaces encargadas de resolver las diferencias de velocidades, voltajes y formatos entre la CPU y los periféricos. Se controlan mediante E/S Programada o mediante Interrupciones de hardware.
  • Acceso Directo a Memoria (DMA): Módulo especial que permite a los periféricos transferir datos directamente hacia y desde la memoria RAM sin usar a la CPU como intermediaria, liberando al procesador de cargas de trabajo masivas.

1.6 Buses e Interrupciones

  • Buses: Autopistas de datos electrónicas. Se clasifican por función: Bus de datos, Bus de direcciones (mapeo de memoria) y Bus de control (sincronización).
  • Interrupciones: Mecanismo físico que altera el orden lógico de ejecución para atender un evento urgente de hardware. Evita la técnica de **poleo (polling)**, en la cual la CPU gasta ciclos de reloj consultando activamente si un periférico requiere atención.

Unidad 2: Estructura y Funcionamiento del Procesador

Microarquitectura

2.1 Organisation del Procesador

La CPU procesa instrucciones y coordina todas las operaciones del sistema. Para optimizar el rendimiento, implementa la **Segmentación (Pipelining)**, permitiendo procesar de manera simultánea diferentes etapas de varias instrucciones a la vez en una estructura de cascada.

2.2 Estructura de Registros

Los registros son celdas de almacenamiento de velocidad extrema integradas dentro del propio procesador. Se dividen en dos categorías principales:

A. Registros Visibles para el Usuario

Manipulados directamente por los programadores de lenguaje ensamblador:

  • Registros de Datos: Acumuladores lógicos para cálculos matemáticos inmediatos.
  • Registros de Direcciones: Almacenan punteros e índices de segmentos de memoria.
  • Registros de Índice: Utilizados para recorrer arreglos de datos mediante autoincrementos.

B. Registros de Control y Estado

Uso exclusivo de la Unidad de Control para mantener el orden secuencial del sistema:

  • Contador de Programa (PC): Contiene la dirección de la siguiente instrucción a ejecutar.
  • Registro de Instrucción (IR / CIR): Almacena la instrucción actual mientras se decodifica.
  • Registro de Dirección de Memoria (MAR): Apunta a la dirección física de la RAM que se va a leer o escribir.
  • Registro Intermedio de Memoria (MBR): Retiene temporalmente el dato binario transferido desde o hacia la memoria.

2.3 El Ciclo de Instrucción (Ciclo FDE)

Línea de tiempo del procesamiento síncrono elemental:

1
Búsqueda (Fetch)

El PC envía la dirección a la memoria principal; la instrucción se aloja en el registro CIR y el PC se incrementa para apuntar a la siguiente celda de memoria.

2
Decodificación (Decode)

La UC interpreta el código de operación (opcode), identifica los operandos involucrados y prepara las rutas de datos internas.

3
Ejecución (Execute)

La ALU realiza la operación (sumas, operaciones lógicas, saltos) y los resultados se guardan en registros internos o se escriben de vuelta en la RAM.

2.4 Modos de Direccionamiento

Metodologías lógicas para localizar datos. Un error de direccionamiento puede provocar fallos masivos de seguridad del sistema.

Modo de Direccionamiento Mecanismo de Operación Ejemplo de Código
Inmediato El dato u operando está incluido dentro de la misma instrucción. MOV AX, 0ABCDH
Directo (Absoluto) La instrucción contiene la dirección de memoria exacta del dato. MOV BX, [1234H]
Por Registro El operando reside dentro de un registro interno del procesador. MOV AX, CX
Indirecto Apunta a un registro que contiene la dirección RAM real. Base de los punteros. MOV AX, [BX]
Indexado y Base + Índice Combina un registro base, un registro índice y un desplazamiento constante. MOV AX, [BX+SI+8]

2.5 Casos de Estudio Reales

Caso 1: Gusano Code Red (2001)

Una aplicación web en C utilizó la función de copiado strcpy con direccionamiento indirecto hacia un búfer sin validar los límites. Un atacante inyectó una cadena que sobrescribió la pila y modificó la dirección del Contador de Programa (PC), infectando a más de 350,000 servidores corporativos en 14 horas.

Caso 2: Memoria Mapeada en ARM Cortex-M

Los periféricos embebidos (GPIO o UART) de un vehículo se controlan mapeándolos directamente en la memoria mediante direccionamiento indexado. Esto permite hacer manipulación física y control de hardware de velocidad crítica automotriz sin demoras.

Unidad 3: Selección de Componentes para Ensamble

Infraestructura

3.1 El Chipset (Conjunto de Chips)

Actúa como el nodo logístico de la placa base, administrando la comunicación entre la CPU y los demás componentes.

Puente Norte (Northbridge)

Controlaba históricamente los componentes de máxima velocidad: CPU, memoria RAM y ranuras de video PCIe. Nota moderna: Actualmente estas funciones están integradas directamente en el silicio de los procesadores actuales.

Puente Sur (Southbridge)

Se encarga de los componentes periféricos y de velocidades más bajas: controladores de almacenamiento (SATA/NVMe), puertos USB, audio integrado, tarjetas de red y ranuras de expansión secundarias.

3.2 Componentes Centrales del Ensamble

Procesador

Se deben evaluar variables críticas como velocidad de reloj (GHz), núcleos e hilos de procesamiento, memoria caché integrada, consumo térmico de diseño (TDP) y el socket de montaje compatible con la tarjeta madre.

Memoria RAM

Factores clave: Capacidad de almacenamiento (GB), velocidad nativa de operación (MHz), tecnología de transferencia (DDR4, DDR5) y las latencias internas CAS (CL).

Placa Base

Variables: Factor de forma del gabinete (ATX, Micro-ATX, Mini-ITX), chipset integrado, compatibilidad de Socket, fases de poder del procesador (VRM) y puertos de expansión de última generación (M.2, PCIe).

Es indispensable validar la potencia total requerida (Watts), el tipo de cableado (Modular para optimizar espacio) y las certificaciones de eficiencia energética (80 Plus Bronze, Gold, Platinum).

3.4 Ambientes de Servicio

Negocios

Sistemas enfocados en la automatización ofimática, administración de bases de datos relacionales y optimización del tiempo de respuesta empresarial.

Industria

Hardware para el control de líneas de producción automatizadas, robótica pesada, logística física de inventarios y sistemas tolerantes a ambientes hostiles.

Comercio Electrónico

Servidores escalables de alta disponibilidad, pasarelas de pago digitales seguras, cifrado criptográfico y procesamiento continuo de datos en la nube.

Unidad 4: Procesamiento Paralelo

Alto Rendimiento

4.1 Aspectos Básicos de la Computación Paralela

Forma de cómputo en la que muchas instrucciones se ejecutan simultáneamente, fragmentando problemas complejos en subtareas concurrentes de manera eficiente.

Sincronización

Mecanismos de control lógico para coordinar el acceso a datos y evitar la corrupción de variables por condiciones de carrera.

Balance de Carga

Estrategia para distribuir las tareas equitativamente entre los núcleos y evitar procesadores inactivos o saturados.

4.2 Clasificación del Paralelismo

  • A Nivel de Bit: Incremento en la longitud de palabra del procesador (migración histórica de registros de 32 bits a 64 bits), disminuyendo los ciclos requeridos para operar números grandes.
  • A Nivel de Instrucción (ILP): El procesador reordena y combina instrucciones para ejecutarlas de forma simultánea (Pipelining / ejecución superescalar).
  • Paralelismo de Datos: Distribuye bloques masivos de datos a lo largo de un arreglo de núcleos simples que ejecutan simultáneamente la misma instrucción (Arquitectura nativa de las **GPUs**).
  • A Nivel de Tarea: Hilos o procesos independientes ejecutan tareas completamente diferentes sobre conjuntos de datos iguales o distintos.

4.3 Limitaciones del Modelo Secuencial Clásico

La computación monoprocesador tradicional llegó a un límite debido a dos barreras físicas: el **Muro Térmico** (el incremento excesivo de frecuencia genera un calor inmanejable que destruye el silicio) y el **Muro de la Memoria** (la velocidad de procesamiento avanza exponencialmente más rápido que los tiempos de acceso a la RAM). Esto forzó el desarrollo de arquitecturas de múltiples núcleos.

4.4 Clasificación (Taxonomía de Flynn)

Clasificación Flujo de Instrucciones Flujo de Datos Arquitectura Común Real
SISD Único Único Computación secuencial clásica (Monoprocesador).
SIMD Único Múltiple Procesadores vectoriales y Unidades de Procesamiento Gráfico (**GPUs**).
MISD Múltiple Único Poco común. Empleado en sistemas redundantes de alta tolerancia a fallos (Aeroespacial).
MIMD Múltiple Múltiple Procesadores multinúcleo comerciales, supercomputadoras y Clusters modernos.

4.5 Organización de Direcciones de Memoria

A. Memoria Compartida (Sistemas Multiprocesador - SMP)

Todos los núcleos comparten un único espacio de direccionamiento global. Se subdivide en **UMA** (mismos tiempos de acceso para todos los núcleos) y **NUMA** (el tiempo de acceso depende de la cercanía física del procesador al módulo de memoria RAM).

B. Memoria Distribuida (Sistemas Multicomputador - Clusters)

Cada nodo cuenta con su propia memoria física privada y exclusiva. No existe un espacio común. La comunicación obligatoria de datos e interconexión entre nodos se realiza mediante el paso de mensajes estructurados a través de una red dedicada.

4.6 Redes de Interconexión Estáticas

Enlaces de hardware físicos fijos entre los nodos que no cambian durante la ejecución del software. Topologías comunes: Lineal, Anillo, Estrella, Malla (Mesh), Árbol y de Hipercubo. Ofrecen una alta eficiencia en comunicaciones de nodos cercanos, pero escalarlas a gran escala eleva drásticamente el costo físico de cableado estructural.

4.7 Casos de Estudio Reales

Intel Core / Xeon

Implementa un bus en anillo (Ring Bus) interno para interconectar los núcleos de computadoras de escritorio, y arquitecturas de malla (Mesh) de alto rendimiento para procesadores masivos orientados a servidores corporativos Xeon.

AMD Ryzen (Chiplet)

Reemplaza el diseño monolítico grande por pequeños bloques funcionales independientes interconectados a máxima velocidad mediante su tecnología propietaria de buses lógicos denominada Infinity Fabric.

NVIDIA GPUs

Diseñadas puramente bajo el enfoque SIMD. Mientras un CPU típico tiene pocos núcleos potentes, una GPU integra miles de núcleos pequeños optimizados para resolver cálculos matemáticos paralelos simultáneos (IA y Renderizado).
